## M0-01 — конкретная задача на старт
- Проверить пустой проект и окружение. Инициализировать Next.js App Router, TS strict, Tailwind, pnpm. Не перезаписывать docs/AGENTS.
- Выбрать совместимые версии по официальным документам; не устанавливать все библиотеки заранее. Создать базовые адаптеры маршрутов /, /workout, /progress, /coach, /profile с нейтральными заглушками и русским текстом. Минимальные public API и направление FSD, без пустых слоёв.
- Настроить ESLint, typecheck, Vitest (smoke), CI на PR/push, production build; README с проверенными командами. Не публиковать, не добавлять авторизацию или бизнес-функции.
- Приёмка: pnpm install, lint, typecheck, test, build (точные команды в README); все маршруты доступны, документация сохранена, lockfile есть. Обновить PROGRESS. Если проверка не выполнена — указать причину.

## M5-03 — граница среза

Использовать существующие nutritionOptIn/nutritionTips: 0–3 пункта до180символов, только при добровольном согласии. Тренер показывает советы из принятого baseline активной версии при текущей ревизии профиля, независимо от нового экспорта. Пустой keep заменяет прежние советы; изменение профиля/отказ/rollback скрывают неактуальные, история не переписывается. Не добавлять дневник калорий, назначения или отдельную анкету. Реализация и автоматические проверки выполнены; native/UI/телефон/диктор и внешняя оценка остаются открытыми (PROGRESS/TESTING). Следующая независимая задача — M6-01 PWA.

## M5-02 — граница среза

Добровольный раздел на Прогрессе: добавить/посмотреть/удалить замер, добавить/посмотреть/удалить отдельное или все выбранные локальные фото. Замеры выбранных пользователем релевантных типов за90дней — в AI-запросе только по отдельному согласию; фото — отдельная очищенная копия с предупреждением, вне JSON. Приёмка включает миграцию без потери прежних таблиц, атомарность/отказы/лимиты файлов, stale контекст opted экспорта и отсутствие обязательной анкеты. Точные результаты и открытые проверки — PROGRESS/TESTING. M5-03 не входит, M5 целиком не закрывается этим срезом.
