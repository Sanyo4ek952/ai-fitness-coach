1. [Мягкое облако](01-soft-cloud.png): равномерное мягкое бирюзовое свечение вокруг активного поля.
2. [Глубокий ореол](02-deep-halo.png): ближний бирюзовый и широкий синий рассеянный слой. Рекомендован под запрос более размытого эффекта.
3. [Световой контур](03-light-contour.png): свет по верхнему краю с мягкой внутренней подсветкой и слабым внешним ореолом.

Проверены изображения: русский текст/три подписи/различающиеся эффекты, активное левое поле и нейтральное правое, читаемые цифры, прежняя палитра. Незначительные генеративные различия компоновки не являются предложением менять текущую страницу.
