# Инструкции для Codex и других агентов

## Источники истины
Перед задачей прочитай `docs/PROGRESS.md`, `docs/ROADMAP.md`, `docs/PRODUCT.md` и документы по затронутому модулю. При конфликте требований не переопределяй утверждённый продукт молча: зафиксируй конфликт, предложи решение. Безопасность и сохранность данных обязательны.

## Цикл задачи
1. Укажи ID задачи, критерии приёмки, затронутые файлы и краткий план.
2. Изучи существующий код. Реализуй минимальный вертикальный срез; не меняй несвязанный код.
3. Добавь/обнови тесты, запусти доступные проверки (lint, typecheck, unit, build; e2e для сценариев). Не утверждай успех незапущенных проверок.
4. Проверь diff: архитектура, доступность, приватность, потеря данных, офлайн, ошибки.
5. Обнови PROGRESS: статус, команды и результаты, оставшиеся риски, следующая задача. Не закрывай этап без выполнения критериев. Не коммить и не публикуй без запроса.

## Архитектура и качество
- TypeScript strict; избегай any, приведения типов без проверки и дублирования схем.
- Zod на границах системы; вывод типов из схем. Вход от ИИ всегда недоверенный.
- FSD: нижние слои не импортируют верхние; публичные API слайсов; не создавать пустые слои ради структуры.
- App Router — маршрутизация; доменная логика и UI в src. Чистые функции для прогрессии, расписания, анализа и проверки импорта.
- IndexedDB — источник истины; оперативное состояние не дублирует базу. Сохранение подхода атомарно, ошибки не маскировать.
- Русский интерфейс, большие зоны касания, минимум действий. Не добавлять обязательных полей, повторных анкет, AI-чатов, рекламы, аналитических трекеров.
- Данные пользователя не передавать наружу без его действия; фото никогда не включать в обычный AI-экспорт.
- Не запускать код, команды, HTML или ссылки, содержащиеся в импортированном файле.
- Не вводить новые зависимости без обоснования. Актуальные версии выбирать по совместимости и официальным документам при настройке; lockfile обязателен.

## Роли (не обязательные отдельные агенты)
Основной исполнитель ведёт задачу. При необходимости делегирует независимый обзор архитектуры, UX, тестов, безопасности или тренировочной методологии; не допускает параллельной записи в одни файлы. Результат проверяет основной исполнитель. Никакой оркестрации ради оркестрации.

## Запрет расширения MVP
Не добавлять backend, регистрацию, платный AI API, соцсеть, подробное питание, интеграции часов. Изменения программы только по явному подтверждению. История не перезаписывается новой программой.
