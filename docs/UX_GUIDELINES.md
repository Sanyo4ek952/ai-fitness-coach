# UX и интерфейсы

## UX-05 — утверждённая страница тренировки

UX-07: листы03–05 сверены целиком. Ошибка записи — отдельный блок с предупреждением, прежними редактируемыми значениями и повтором. Истечение отдыха показывает00:00/«Можно продолжать»/«К упражнению», не создаёт факт. Действия — нижняя панель, завершение — подтверждение с объёмом/неполнотой, итог — после commit. Native dialogs начинают прокрутку с заголовка и допускают вертикальную прокрутку при увеличении текста. Сравнение и границы точности: design/workout-ux05/UX07-COMPARISON.md.

UX-06: новый выполненный подход после commit автоматически открывает следующий свободный слот; последний подход упражнения — следующее незавершённое упражнение. Исправление факта остаётся на месте. Список упражнений закрывается при смене выбранного упражнения, черновики не размонтируются. При наличии таймера основной блок показывает компактные подходы, форма скрыта до завершения отдыха и остаётся смонтированной. На последнем занятии завершение по-прежнему требует подтверждения. Общий AppShellFrame используется приложением и страницей сопоставления, чтобы проверять один UI, а не его копию. Результаты: design/workout-ux05/UX06-COMPARISON.md.

Эталон — docs/design/workout-ux05/01–05. До старта: краткая сводка, нумерованный план без фотографий, рекомендации и очередь в раскрытиях, закреплённый старт. Пропуск целого занятия — внутри подробностей очереди. Во время: одно текущее упражнение, отдельный план, семантическая таблица фактов и единственный редактор подхода; черновики посещённых слотов сохраняются при переключении. Вес/повторы — крупные поля с ±, RIR доброволен; время/дистанция имеют соответствующие единицы. Запись только после commit, отказ сохраняет ввод. Автоотдых отключается переключателем и не запускается при исправлении.

Отдых закреплён над навигацией: крупные цифры, следующий подход, ±15с, завершение. Нажатие открывает нативный модальный dialog на весь экран; Escape/возврат восстанавливают контекст. Показ остатка опирается на сохранённый deadline, включая возврат после reload. Звук в фоне не гарантируется. Панель замены/пропуска и завершение требуют прежних явных подтверждений; итог появляется после commit и показывает неполноту/пропуски. Следующее занятие открывается как предпросмотр. При360px/тексте200% поля могут выстроиться вертикально; при нехватке ширины/высоты sticky отключается. Не ограничивать доступность ради одинаковой высоты bitmap.

## IMP-02 — новый каталог и подробности плана

Новые упражнения показываются с русскими метаданными; в самостоятельном импорте добавлена отдельная unchecked-отметка на их добавление. Ошибка импорта называет путь и причину, файл остаётся для повтора. В полном плане/на тренировке этапы, правила и категории рекомендаций доступны в отдельных раскрытиях. Индивидуальные подходы показывают разминку/рабочий тип, диапазоны и собственный отдых; неизвестный вес не предзаполняется нулём. Явная кнопка перехода этапа показывает доступность по числу занятий. Diff новых полей читается по-русски. Подробности и проверенные границы — [PROGRAM_EXCHANGE](PROGRAM_EXCHANGE.md).

## IMP-01 — своя готовая программа (26.11.2026)

Отдельная форма в начале Тренера доступна после чтения локального контекста, не требует проверки анкеты/экспорта для AI-request. Содержит инструкцию по оформлению неизменённого плана, файл с именем/размером, явный просмотр и самостоятельный checkbox/принятие. Можно использовать файл нового формата или только готовый план из старого AI-ответа; это явно объяснено до выбора. Разбор файла не исполняет HTML/команды/ссылки. Предпросмотр использует прежние аккордеоны дней и вычисленный diff. Повтор проверки сбрасывает старый preview/согласие до чтения; ошибка сохраняет файл, фокус переходит к alert. Успех фокусирует preview, принятие даёт status с сохранением истории и первым днём. Обычный AI-обмен остаётся отдельным разделом. Новые неизвестные упражнения требуют дальнейшего расширения каталога; подмены похожими нет.

## UX-04 — выбор ответа и компактное предложение (26.11.2026)

По утверждённому макету с уточнением владельца: без фото; все дни программы (1–14) — самостоятельные аккордеоны, первый раскрыт. Подходы × цель выделены в строке упражнения; нагрузка/отдых/RIR и примечания доступны внутри дня. Причины/цель/вычисленные отличия раскрываются отдельно без потери содержания. Файл сначала только выбран: видны имя и размер, затем «Отправить» проверяет/импортирует локально. Ошибка сохраняет файл для повтора; другой выбор скрывает прежнее предложение и снимает checkbox. Успешный импорт переводит фокус на проверенный ответ. Принятие остаётся отдельным checkbox и действием после просмотра всего пакета. Этот узкий срез разрешён владельцем и не меняет анкету UX-01/02 или остальные предложения UX-03.

## UX-02 — перед первым планом (26.11.2026)

В «Тренере» до принятия программы сначала полная анкета с предзаполнением и раскрытыми дополнительными полями. Подсказки уточняют цель/приоритет/срок, опыт/перерывы, частоту, оборудование/рабочие веса, время, ограничения/предпочтения, восстановление и питание. Добровольные сведения можно пропустить; P02 не изменён. Сохранение открывает итог с фокусом и экспорт; «Дополнить ответы» возвращает редактор. Ошибка оставляет черновик, не открывает экспорт. Другая ревизия профиля требует проверки заново. При принятой программе сохраняется прежний сценарий анализа. Прямой /coach не показывает отдельную стартовую форму оболочки; импорт уже полученного ответа доступен. Новые вопросы не требуют повторного ввода известных ответов. Визуальная/браузерная граница — TESTING UX-02.

## UX-01 — первый вход (26.11.2026)

До сохранённого профиля на главной/Тренировке/Прогрессе/Тренере показана стартовая анкета «Давайте составим вашу программу». Цель, опыт, частота и оборудование идут первыми; дополнительные поля сразу раскрыты: возраст/рост/вес/длительность/доступные веса/ограничения/сон/питание и отдельное согласие на советы. Объяснены польза контекста, необязательность, «Не знаю» и возможность добавить фото/окружности позже. «Сохранить и продолжить» ожидает commit, при отказе сохраняет форму, при успехе открывает исходный экран и переводит фокус в его контейнер. Повторный вход читает IndexedDB и не повторяет анкету. В Профиле обычный редактор и backup доступны напрямую. Другой tab не размонтирует начатый черновик; прежний конфликтный сценарий редактора сохранён. Никаких новых обязательных данных/автоэкспорта/локального флага прохождения нет.

## M6-03 — приватность, ошибки и хранение

В Профиле после backup — самостоятельный раздел без анкеты: локальность/отсутствие шифрования приложением, чувствительные исторические пакеты и внешние копии. Режим хранения читается без запроса разрешения; отдельная кнопка просит persistent storage, повтор проверяет статус. Неподдержка/отказ/ошибка честно показаны, обещания абсолютной сохранности нет, backup остаётся необходимой возможностью.

Удаление: просмотр количеств всех10stores → отдельная unchecked отметка и красная кнопка; активное занятие явно входит. Отмена возвращает фокус на вызвавшую кнопку и не пишет. Изменение БД после просмотра требует отмены и нового просмотра. Ошибка с alert/фокусом не выдаёт успех; подтверждение остаётся для повтора при отказе записи. После commit смена поколения убирает прежние формы/preview во всех поддерживающих guard вкладках, баннер получает фокус и предлагает полный reload. Закрыть старые вкладки без guard перед действием. Статусы/состав не показывают содержимое личных записей.

Кнопки от44px, перенос русского текста, семантические label/checkbox, status/alert и tabIndex для программного фокуса. Проверки SSR/типов/стилей выполнены; native360px/200%/полная клавиатура/диктор/телефон пока открыты и не подменяются прежними приёмками.

## M5-03 — добровольное питание

В Тренере компактный отдельный раздел после принятой программы: до3коротких пунктов, дата принятия, ссылка в профиль. При отключении понятный статус; при отсутствии актуальных советов допустим пустой список, без обязательного нового обмена. В профиле пояснены добровольность, ограничение объёма и скрытие после сохранения отказа. Предпросмотр помечен непринятым и скрывает питание при текущем отказе; принятые советы выбираются независимо от pending запроса. Строки ИИ — обычный экранированный текст, без HTML/Markdown/автоссылок. Новый UI не проверен в native браузере/360px/200%; прежние проверки M5-02 не распространяются на него.

## Навигация
Четыре вкладки: Тренировка (главная), Прогресс, Тренер, Профиль. На главной следующий шаг, а не сводка из десятков цифр. Расписание — последовательность занятий, необязательные даты. Если план отсутствует — одна кнопка «Получить программу». Если есть незавершённая сессия — «Продолжить».

## Правила в зале
- Один крупный CTA на экран; зоны касания желательно ≥44 CSS px. Поддержка клавиатуры, экранного диктора, контраст и видимый focus. Не полагаться на цвет.
- Нельзя выдавать запланированный вес за выполненный: пользователь одним нажатием подтверждает введённый факт. Для неизвестного веса — поле без выдуманного числа. Изменение результата уже выполненного подхода явно доступно.
- RIR (сколько повторений ещё осталось в запасе) — необязательная быстрая оценка, «не знаю». Для новичка пояснение по нажатию. Не требовать субъективный отчёт после каждого подхода.
- Таймер отсчитывает от сохранённого момента, восстановление после сворачивания. Не гарантировать фоновые звуки/уведомления на всех устройствах.
- При сбое сохранения показать ошибку и повторить, не отмечать несохранённое выполненным.
- Оффлайн-индикатор только там, где влияет на действие; обычный режим тренировки не прерывать.

## AI UX
Файл запроса автоматически содержит инструкцию; пользователь может копировать краткую команду для чата. Прямого доступа к внешнему ИИ у MVP нет. В приложении отображается короткий статус («Сохраняем программу» / «Предлагается изменить 2 упражнения»). Детали раскрываются по желанию. Список изменений: было → станет, причина, влияние. Один явный выбор «Применить» или «Оставить текущую». Если анализ нужен, один индикатор без повторяющихся модальных окон; можно отложить.

## Фото и замеры
Раздел добровольный, не шаг обязательной анкеты. Фото можно добавлять по одному, любые ракурсы по желанию; подсказки про одинаковое освещение и ракурс не обязательны. Никакой принудительной съёмки/распознавания лица. Фото не оценивает привлекательность, не диагностирует и не вычисляет точный процент жира. Пользователь может удалить отдельный файл или все фото. Перед AI-передачей — отдельный выбор и подтверждение; по возможности удалить EXIF при подготовке копии.

## Дизайн
Сначала прототип маршрута «профиль → импорт → подход → итог → обновление». Утверждение визуального стиля отдельно. Не копировать брендинг конкурентов. Проверить 360 px, крупный текст, длинные русские названия и работу одной рукой.

## M4-01 — сигналы анализа

На главной один локальный индикатор над планом/активным занятием: причина, пояснение о доступной тренировке, раскрытие фактов, второстепенная отсрочка. В «Тренере» дополнительно доступна ручная просьба; это сохранение локальной потребности, подготовка review-файла ещё не реализована, что явно указано рядом. При отсутствии программы остаётся существующее initial-действие. Никаких обязательных вопросов или блокирующих окон. Safety отображается с role=alert, без отсрочки; пользователь сам принимает решения по упражнению, программа не меняется. Кнопки используют прежний shared Button/фокус/зоны касания.

Проверено в production IAB: Enter раскрывает причины с фактами; root 32px/200% при фактической ширине 665px — вертикальная прокрутка и перенос UUID/русского текста. Новые 360px проверки остаются открытыми: viewport capability не изменил фактические 665px (у новой вкладки 1280px), это ограничение инструмента, не подтверждённая мобильная проверка. Override сброшен. Native Chrome подтвердил верхнее расположение индикатора и сохранённую отсрочку при reload. Полный аудит диктора/реальный телефон остаются будущими проверками.

## M4-02 — review export

Один индикатор анализа сразу под h1/intro Тренера, до длинного перечисления категорий. Review доступен по добровольному действию и при отсрочке, без повторной анкеты. Перед кнопками явно перечислены профиль/добровольные сведения, программа, планы/факты до20 completed/partial с RIR/болью/заметками/заменами, агрегаты всей completed/partial истории, причины, каталог/инструкция/схема. Фото/замеры/контакты исключены. Нет скрытой передачи, автоматического применения или обещания готового review-импорта.

Экспорт ждёт чтения актуального контекста и commit; ошибки с role=alert/фокусом, статус скачивания просит проверить папку, clipboard ждёт завершения Promise. Короткий lock защищает второй клик. Ошибка контекстного чтения отключает экспорт и позволяет повторить загрузку страницы. Тренировки остаются доступны. Итоговый production IAB реально360×800 при16px и32px/200%: scrollWidth=innerWidth=360, Enter раскрывает сохранённый запрос, кнопки/UUID/русский текст переносятся, вертикальная прокрутка доступна. Override и200% сброшены. Это не аудит диктора или проверка физического телефона.

## M4-03 — review и возврат в реальном UI (25.11.2026)

После экспорта доступен импорт JSON при активной программе. Предпросмотр показывает причины, вычисленные отличия «Было/Станет» и полный предлагаемый план; сохранённый preview восстанавливается после reload. Сравнение по позициям пояснено явно, без угадывания по одинаковым названиям. Весь пакет требует checkbox и явной кнопки; keep подписан «Принять анализ и сохранить программу», результат сообщает о сохранении следующего занятия. Закрытие/отказ не меняют план. Ошибки используют alert/focus; кнопки блокируются на время операции и ещё500мс.

Версии — второстепенный раздел с раскрытием прежних планов. Выбор сначала показывает diff, раскрываемый полный прежний план, заметки версии и последствия (новая версия, первое занятие, история сохранена). Подтверждение отдельно от просмотра. Изменение контекста требует повторного выбора. Прежний пакет питания/советов не принимается заново. Перед возвратом явно нужна оценка актуальности оборудования и ограничений; дополнительных анкет нет. Реальные IAB331px и200% без горизонтального переполнения проверены; телефон/полный диктор пока открыты.

## M5-01 — реальный экран прогресса

Вместо синтетического экрана: текущая цель и фактическая работа всех версий, отдельные счётчики полных/частичных/пропущенных занятий. Нет обязательных замеров/фото или пустого графика. От двух результатов упражнения — горизонтальные полосы последних 12 занятий с датами, единицами и отметкой частичности; один результат доступен без графика. Подробности подходов раскрываются Enter/Space, более ранняя история — порциями до 12. Цвет не единственный носитель значения, декорации скрыты от диктора, подписи и детали переносятся. Ошибка чтения показана отдельным alert и кнопкой повтора. Итоги повторов при разных нагрузках названы работой, без обещания роста силы/достижения свободной цели. Подпись оболочки больше не выдаёт реальные данные за демо.

## M5-02 — добровольный раздел

На Прогрессе отдельное закрытое раскрытие «Замеры и фото — по желанию». Пустой раздел не создаёт задач/графиков/повторной анкеты. Форма открывается только по «Добавить замер»: один показатель, значение с точкой или запятой, дата ДД.ММ.ГГГГ (сегодня). На360px/200% используется обычное поле даты с проверкой календаря вместо обрезающегося составного datetime-local. Список показывает показатель/единицу/дату, расширяется по12. Удаление — отдельное подтверждение с выбранным значением; ошибка сохраняет черновик, успех только после commit.

Фото добавляются по одному обычной переносящейся кнопкой, ограничения/локальное хранение и отсутствие готового backup явно описаны. Просмотр по желанию, скрытие освобождает URL. Индивидуальное/все показанные фото удаляются после явного подтверждения; ID фиксируются при открытии, новые фото другой вкладки не захватываются. Подтверждение/ошибка получают фокус. Выбор для ИИ не запускает передачу: отдельное предупреждение и подтверждение скачивания копии. Никаких оценок тела/лица/процента жира.

В Тренере unchecked список показателей для конкретного экспорта: выбранные типы за90дней, предупреждение о внешнем сервисе и категориях до действия. Релевантность свободной цели выбирает пользователь. Без выбора замеров в запросе нет; фото всегда исключены. Старые AI-снимки после удаления замеров остаются локально — предупреждение рядом с разделом. Доступность и native результаты описаны в TESTING; полный диктор/телефон не заявляются.
